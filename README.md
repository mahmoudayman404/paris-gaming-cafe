# PARIS — Gaming & Café

موقع Front-End فقط، بدون Backend أو قاعدة بيانات. شغّله باستخدام VS Code Live Server أو أي static web server محلي.

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد `paris` في VS Code.
3. شغّل `index.html` عبر Live Server (مهم لتفعيل Web Crypto في صفحة الحساب).
4. صفحة الحساب من زر **حسابي** أو مباشرة `auth.html`.

## هيكل الملفات
- `index.html` — الصفحة الرئيسية.
- `style.css` و`script.js` — التصميم وسلوك الموقع.
- `gaming.js` — أجهزة PlayStation والبلياردو والبينج بونج.
- `drinks.js` — المشروبات وأسئلتها الاختيارية.
- `desserts.js` — الوافل والبان كيك.
- `auth.html`, `auth.css`, `auth.js` — تسجيل الدخول والتسجيل والملف الشخصي.
- صور المنتجات موجودة في نفس المجلد الرئيسي.

## الحسابات المحلية
- التسجيل باسم كامل واسم مستخدم وبريد إلكتروني وكلمة مرور.
- تسجيل الدخول بالبريد أو اسم المستخدم.
- منع تكرار البريد واسم المستخدم.
- صورة شخصية اختيارية (JPG / PNG / WEBP، بحد أقصى 1.5MB).
- مؤشر قوة كلمة المرور، إظهار/إخفاء كلمة المرور، Remember Me، وتسجيل الخروج.
- استعادة كلمة المرور محلياً عبر البريد المسجل؛ لا يتم إرسال بريد أو كود تحقق.
- تصدير الحسابات إلى `users.json` واستيراد ملف JSON متوافق.
- كلمات المرور لا تُحفظ كنص صريح؛ تُشتق بصمة PBKDF2-SHA256 مع Salt باستخدام Web Crypto.

### حدود مهمة
هذا نظام Demo على نفس المتصفح والجهاز. البيانات محفوظة في `localStorage` ويمكن للمستخدم أو أدوات المتصفح تعديلها أو حذفها. تشفير كلمة المرور لا يحوّل LocalStorage إلى مصادقة آمنة ولا يوفّر استعادة هوية حقيقية. لا تستخدم بيانات شخصية أو كلمات مرور حقيقية. استعادة كلمة المرور ليست آمنة لأنها لا تتضمن تحققاً عبر البريد. ملف JSON المصدّر يحتوي على بصمات كلمات المرور المشفرة وبيانات المستخدمين؛ احتفظ به بشكل خاص. لا توجد مزامنة بين الأجهزة ولا يمكن للمتصفح تحديث `users.json` تلقائياً.

## تعديل المنيو
- `drinks.js` — المشروبات والأسعار والاختيارات.
- `desserts.js` — الحلويات والصوصات.
- `gaming.js` — الألعاب والأسعار والحالة (`available` أو `unavailable`).
- عند تغيير الصور، حدّث مسار `img` في ملف البيانات.

## ملاحظات فحص النسخة
تم تصحيح مسارات تحميل ملفات بيانات المنتجات لتطابق الملفات الموجودة فعلياً، وتصحيح مسارات صور الألعاب. نظام العربة والحجز والواتساب والفلترة والثيم يظل في الواجهة الحالية. الحجوزات والطلبات تظل طلبات مبدئية يرسلها المستخدم عبر واتساب ولا يتم تأكيدها آلياً.
